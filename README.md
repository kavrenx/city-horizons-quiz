# Городской кругозор

Готовый адаптивный квиз ко Всемирному дню городов, 31 октября 2026 года.

[Открыть квиз](https://kavrenx.github.io/city-horizons-quiz/)

## Запуск

В этой папке выполните `npm start` и откройте http://127.0.0.1:4173.
Достаточно установленного Node.js, дополнительных пакетов нет.

Для размещения на обычном статическом хостинге загрузите **содержимое `dist`**.
Сайт не требует сервера приложений, базы данных или API-ключей.

## Публикация на GitHub Pages

Сайт автоматически публикуется после отправки изменений в ветку `main`.
GitHub Actions сначала выполняет `npm run check`, затем размещает содержимое `dist`.
Настройки публикации находятся в `.github/workflows/pages.yml`.
В настройках репозитория **Settings → Pages → Source** выбран **GitHub Actions**.

Для публикации обновлений:

```sh
git add .
git commit -m "Update quiz"
git push
```

Проект не использует сторонние npm-пакеты и не требует установки зависимостей.

## Что реализовано

- 41 вопрос, четыре исходные темы, по три правдоподобных варианта.
- Случайный порядок вариантов при каждом новом прохождении.
- Явное подтверждение ответа, пояснение и ссылка на источник.
- 1 балл за верный ответ, 0 за ошибку или «Пока не знаю». Максимум 41.
- Никаких ограничений по времени или штрафов за скорость.
- Автосохранение в localStorage, продолжение и просмотр прошлых вопросов.
- Результат по темам, процент правильных ответов, пять уровней и рекомендации по двум слабейшим темам.
- Фильтры полного разбора: все, ошибки, верные, «не знал(а)» и тема.
- Отдельная тренировка по ошибкам, которая не переписывает основной результат.
- Скачивание текстового отчёта со всеми ответами, пояснениями и источниками.
- Адаптивная вёрстка, управление клавиатурой, контрастные состояния и поддержка уменьшенного движения.
- Локальные фотографии и шрифты. Имена и контакты участников не собираются.

## Редактирование

`dist/data.js` — вопросы, варианты, пояснения, темы и источники.
`dist/app.js` — интерфейс, автосохранение и оценивание.
`dist/style.css` — оформление и адаптивные размеры.
`dist/assets/credits.json` — авторы и лицензии фото Wikimedia Commons.
`CONTENT-NOTES.md` — уточнения исходного материала.

После изменения содержания вопросов измените `version` в `data.js`, чтобы не подмешивались ответы на прежнюю редакцию.

Проверка содержимого: `npm run check`.

## Хранение результатов

Сохраняется только текущее прохождение и последний завершённый основной результат в данном браузере. Очистка данных браузера удаляет прогресс. Общего рейтинга и удалённого учёта участников нет. Для следующего человека на общем компьютере нажмите «Пройти все 41 заново» на экране результата.
